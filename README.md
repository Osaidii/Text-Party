# Text Party
Text Party is a text collaboration software that is straight to the point.  

## Description
You can use it like a normal notepad or invite members to edit the same document.  
None of your data is stored other than that required by our server to keep you connected to you members.

## Dependencies
There are no dependencies to run the .exe file other than the _internal folder and the .exe itself.
IF you want to run the code itself, you only need python (tkinter on linux aswell).
Right now only windows client works but future updates will add more platforms.  
The server only works and will only work for Linux.

## Core ideas:
This is supposed to be a co op software that is an open source alternate to google docs or software like it.  
None of you data is stored on the Text Party servers except that required to connect you to your party members.  

## AI Declaration
