# Text Party
Text Party is a text collaboration aoftware that is straight to the point.  
You can use it like a normal notepad or invite members to edit the same document.  
You can download the software from the [releases](https://github.com/Osaidii/Text-Party/releases) page or at the [website](https://osaidii.com/Text-Party)   

## Core ideas:
This is supposed to be a co op software that is an open source alternate to google docs or software like it.  
None of you data is stored on the Text Party servers except that required to connect you to your party members.  

## AI Declaration
Some parts of the software were written by AI but under human supervision since I am still learning.
AI was also used for debugging the software.  

## Platforms
Right now the software only works on windows and the Server only works and is only meant to work on Linux. The rest of the files on the website are dummy files.
